# Biblo-Folder-Lite
Biblo Folder Lite es la edición gratuita y limitada de Biblo Folder Premium, la versión completa de pago. Organiza el escritorio de Windows en hasta 2 carpetas con un máximo de 4 elementos cada una. Incluye funciones básicas para mover, abrir y devolver elementos. Las funciones avanzadas están disponibles en Premium.

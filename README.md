# Biblo-Folder-Lite
Biblo Folder Lite is the free, limited edition of Biblo Folder Premium, the full paid version. It organizes your Windows desktop into up to 2 folders with a maximum of 4 items each. Includes basic functions to move, open, and restore items. Advanced features are available in Premium. 

Get the Premium version at this link: https://biblofolder.sell.app/product/biblo-folder-premium?quantity=1

Known Issue & Upcoming Update:
We are aware of an issue where desktop folders may not appear after restarting your computer until Biblo is manually opened. This happens because the app does not currently launch automatically with Windows.

We are fixing this in the next update by adding an option to enable Auto-Start on Boot, which will be available in both the Lite and Premium versions.
